# 🚀 DSA In Real Life - Binary Tree 
This folder contains a collection of real-life inspired projects that demonstrate how the **Binary Tree** data structure can be applied in practical scenarios.

Each project is designed for educational purposes, focusing on illustrating core concepts and problem-solving approaches using Binary Tree rather than serving as fully featured, production-ready applications.

## 📦 Projects in This Category

### 🎧 Eval Tree App (Expression Tree)
- Naive approach using the python `eval` build-in function.
- Improved implementation using a **Expression Tree**
    - Requirements:
        - Support basic arithmetic operators: `+`, `-`, `*`, `/`
        - Handle operator precedence correctly
        - Handle parentheses (e.g., `"(2 + 3) * 4"`)
        - Assume the input is a valid expression
